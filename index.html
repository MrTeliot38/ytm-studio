Guide rapide Google Cloud Console (YouTube Data API v3)
  1. Dans Google Cloud Console, activez l'API YouTube Data API v3.
  2. Configurez l'Écran de consentement OAuth (type Externe) et ajoutez votre adresse Google dans les Utilisateurs tests si l'app est en mode Test.
  3. Créez un identifiant ID client OAuth → Application Web.
  4. Dans Origines JavaScript autorisées, collez l'origine affichée ci-dessus (sans slash final ni chemin).
  5. Copiez le Client ID obtenu dans le champ ci-dessus et sauvegardez.
